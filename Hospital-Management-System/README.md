# 🏥 Hospital Management System

A modern, responsive, frontend-based Hospital Management System developed using React.js and Vite as an individual internship project.

The application provides a centralized interface for managing hospital operations, including patients, doctors, appointments, billing, wards, beds, and hospital settings.

## 📌 Project Information

- **Project:** Hospital Management System
- **Project Type:** Individual Internship Project
- **Level:** Beginner to Intermediate
- **Duration:** 7 November – 20 November 2026
- **Technology:** React.js, JavaScript, CSS, Vite
- **Application Type:** Frontend Only

## ✨ Features

### 1. Dashboard
- Hospital overview and statistics
- Appointment and patient registration charts
- Weekly and monthly data visualization

### 2. Authentication
- Demo login functionality
- Admin, Doctor, and Receptionist roles
- Role-based application access

### 3. Patient Management
- Add new patients
- View patient details
- Edit and delete patient records
- Search and filter patients
- Export patient records to CSV and PDF

### 4. Doctor Management
- Manage doctor information
- View doctor profiles
- Search doctor records
- Manage departments and availability

### 5. Appointment Management
- Create and manage appointments
- Update appointment statuses
- Calendar and table views
- Search and filter appointments

### 6. Billing Management
- Create and edit invoices
- Manage payment statuses
- Filter invoices by payment status
- Automatic invoice calculations
- Export invoices to CSV and PDF

### 7. Wards & Bed Tracker
- View hospital wards and beds
- Add new wards and beds
- Assign available beds to patients
- Release occupied beds
- Track available, occupied, and maintenance beds

### 8. Settings
- Update profile information
- Update hospital information
- Manage notification preferences
- Light and dark mode
- Configure date and currency preferences

## 🚀 Installation and Setup

- Node.js
- npm
- Git

```bash

```


## 💾 Data Storage

This is a frontend-only demonstration project.

- Demo data is used to demonstrate hospital operations.
- Browser LocalStorage is used for client-side data persistence.
- No backend server or external database is required.

## ⚠️ Current Limitations

- Password changes are not connected to a real authentication backend.
- Notification preferences are stored locally; actual email delivery is not implemented.
- Editing existing wards and beds is not currently available.
- This project is intended for demonstration and internship evaluation, not real hospital operations.

## 🎯 Project Objective

The objective of this project is to demonstrate practical frontend development skills, including React components, routing, CRUD operations, state management, responsive UI design, LocalStorage persistence, accessibility, and software testing.
